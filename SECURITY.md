# Security

Report suspected vulnerabilities to security@magdox.io. Do not open public issues for security reports.

We aim to acknowledge a report within 3 business days and to give an initial triage assessment within 5 business days. The disclosure policy, scope, response targets, coordinated disclosure period and safe harbour are published at https://magdox.io/responsible-disclosure/.

## Supported versions

Security fixes are released in the latest version of the MAGDOX MCP server. Older releases are not supported: upgrade to the latest release. For paid MAGDOX products, support runs for the term of the customer's active subscription or support agreement.

## Advisories and releases

Fixed vulnerabilities are published as security advisories at https://github.com/Magdox/MCP/security/advisories and in the release notes at https://github.com/Magdox/MCP/releases.
